## Overview

Everything in this beta comes out of @RickyReds' v1.4.0-beta.1 test report on real hardware
(two ZR-PLUG accessories, including one with a failed relay that made the offline-at-startup
case testable). If you are new to the 1.4.0 series, read the
[v1.4.0-beta.1 notes](v1.4.0-beta.1.md) first — this file covers only what changed since.

## What's Changed

### Added

- **Stale-entity cleanup.** Un-pairing an accessory from the Red Cap now removes its entities
  automatically on the next poll: the accessory stops emitting its `DEVHA<n>` row, the
  integration prunes its data, and the entities leave the registry. Removal is slot-level, so
  an accessory that is merely **offline** (which still emits its row) keeps its entities and
  their last-known values, exactly as in beta.1. Re-pairing recreates everything cleanly.

### Changed

- **Accessory Relay is definitively read-only.** The `@rel <n> <state>` addressing hypothesis
  was tested on real hardware and falsified — the device accepts a non-zero index and
  **silently ignores it**, replying exactly as to a bare `@rel`. No switch entity will be
  added unless a working command is ever captured from the official app's local traffic.

### Documentation

New Known Limitations in the README, all from real-hardware findings:

- **Accessories may lose part of their internal Wh counter on power loss** (device
  limitation): after a power cycle an accessory can report a *lower* energy total, and HA
  statistics adjust downward. The integration cannot detect it — the value arrives from an
  online accessory. Understated, never inflated.
- **Relay is not a reachability indicator**: it keeps its last state when the accessory is
  physically unplugged. Automations must watch **Online** for reachability.
- **Accessory relays cannot be switched via the local protocol** — relay control remains
  exclusive to the 4-noks app.

## Installation

**HACS**: open the integration page → ⋮ → *Redownload* → enable "Show beta versions" → select
1.4.0-beta.2 → restart Home Assistant.

**Manual**: download `4noks_elios4you.zip` from this release, replace the
`config/custom_components/4noks_elios4you/` folder with its contents (over SSH/Samba), and
restart Home Assistant.

## For beta testers

Carried over from beta.1 plus one new case:

1. **Un-pair an accessory** from the Red Cap while HA runs: its entities should disappear on
   the next poll (and reappear if you re-pair it).
2. **Pair a genuinely new accessory** while HA runs: entities should appear on the next poll
   with no reload — still the one dynamic-creation case without hardware confirmation.
3. Everything from the [beta.1 checklist](v1.4.0-beta.1.md#for-beta-testers) still applies.
